# Budgeting

> **Status:** Planned for Phase 4. This feature is not yet implemented.

RustVault will provide envelope-style budgeting to help you plan and track spending.

## Planned Features

- **Budget envelopes** — allocate a monthly amount per category (e.g. €300 for Groceries)
- **Progress tracking** — see how much of each envelope has been spent, with visual progress bars
- **Rollover** — unspent amounts can optionally roll over to the next month
- **Forecasting** — project future balances based on recurring patterns
- **Dashboard widget** — budget progress shown on the main dashboard

## How It Will Work

1. Create a budget and assign categories with monthly limits
2. As transactions come in, spending is automatically tracked against envelopes
3. Alerts notify you when approaching or exceeding limits
4. Monthly summaries show budget vs. actual spending
