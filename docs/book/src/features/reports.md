# Reports & Charts

> **Status:** Planned for Phase 5. This feature is not yet implemented.

RustVault will provide interactive financial reports and visualizations.

## Planned Reports

| Report | Description |
|--------|-------------|
| **Spending by category** | Bar/pie chart of expenses grouped by category |
| **Income vs. expenses** | Monthly comparison over time |
| **Net worth over time** | Line chart showing total balance across all accounts |
| **Cash flow** | Monthly inflows and outflows |
| **Category trends** | How spending in a category changes month over month |
| **Tag breakdown** | Spending grouped by tags |

## Planned Features

- **Date range selection** — preset ranges and custom date pickers
- **Drill-down** — click a chart segment to see the underlying transactions
- **Export** — download reports as CSV or PDF
- **Filtering** — scope reports to specific accounts, categories, or tags
- **Currency normalization** — multi-currency totals converted to a base currency
