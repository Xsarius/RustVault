# MT940

MT940 (SWIFT Message Type 940) is a standardized bank statement format used primarily by European banks.

## Auto-Detection

MT940 files are identified by their opening SWIFT tag — the content starts with `:20:` followed by a transaction reference.

Accepted extensions: `.mt940`, `.sta`

## Format Overview

MT940 uses tagged fields:

| Tag | Description |
|-----|-------------|
| `:20:` | Transaction reference number |
| `:25:` | Account identification |
| `:28C:` | Statement number / sequence |
| `:60F:` | Opening balance |
| `:61:` | Statement line (date, amount, type) |
| `:86:` | Transaction description / details |
| `:62F:` | Closing balance |

Each `:61:` / `:86:` pair represents one transaction.

## Extracted Fields

RustVault's MT940 parser extracts:

| Field | Source |
|-------|--------|
| Date | `:61:` value date |
| Amount | `:61:` amount with debit/credit indicator |
| Description | `:86:` information text |

## No Column Mapping Needed

MT940 has a fixed structure, so the **Configure** step is skipped during import. Just upload the file, select the target account, and review the preview.

## Tips

- **Multi-statement files** — a single `.mt940` file can contain multiple statement blocks. All are parsed.
- **Character encoding** — MT940 uses a limited SWIFT character set. Special characters may appear as transliterations.
