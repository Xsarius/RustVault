# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |
| Previous minor release | ✅ (critical / high severity only) |
| Older releases | ❌ |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Please report privately via one of the channels below:

- **GitHub private advisory** (preferred): [Submit here](https://github.com/Xsarius/RustVault/security/advisories/new)

For the full security policy — scope, severity classification, disclosure timeline, PGP key, and hardening guidance — see [`docs/security/SECURITY.md`](docs/security/SECURITY.md).
